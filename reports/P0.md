- **Packaging**:

  - `openwrt/geovpn-core/Makefile`: Backend service, OpenVPN supervisor, policy routing, and updater.
  - `openwrt/luci-app-geovpn/Makefile`: LuCI interface definition leveraging `luci.mk`.
  - `openwrt/geovpn-data-seed/Makefile`: Optional starter offline dataset package.
- **Tools**:
  - `tools/lint.sh`: Static analysis runner for shell, JSON, JavaScript, ucode, and translation files.
  - `tools/build-sdk.sh`: Build automation script for OpenWrt SDK on `ipq40xx/chromium`.
  - `tools/mk-feed.sh`: APK repository index generation and signing tool.
- **CI/CD Workflows**:
  - `.github/workflows/build.yml`: Lint, unit test execution, and SDK build matrix for `25.12.5`.
  - `.github/workflows/test.yml`: Integration test harness execution.
  - `.github/workflows/data-pack.yml`: Nightly compilation and usign signing of data packs.
  - `.github/workflows/release.yml`: Release artifact generation, signing, and feed deployment.
- **Project Documentation & Governance**:
  - `LICENSE`: Apache License Version 2.0.
  - `CHANGELOG.md`: Keep a Changelog format.
  - `DECISIONS.md`: Authoritative verification and architectural decision log.
  - `TRACEABILITY.md`: Matrix covering all `FR-*`, `NFR-*`, `C-*`, and `G*` requirements.
  - `tests/integration/run.sh`: Linux network namespace (netns) integration test harness.
