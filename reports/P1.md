## 2. What Was Implemented
- **Configuration & Persistence**:
  - `openwrt/geovpn-core/files/etc/config/geovpn`: Default UCI configuration schema (`main` and `data` singletons).
  - `openwrt/geovpn-core/files/etc/uci-defaults/90-geovpn`: Idempotent first-install setup, file permission enforcer (0700/0600), and migration hook.
  - `openwrt/geovpn-core/files/lib/upgrade/keep.d/geovpn`: Preserves `/etc/config/geovpn`, `/etc/geovpn/profiles`, and `/etc/geovpn/keys` across `sysupgrade -k`.
- **Core Libraries (`/usr/share/ucode/geovpn/`)**:
  - `util.uc`: Strict regex-based whitelist validators (`is_ifname`, `is_profile_id`, `is_category_code`, `is_mac`, `is_ipv4`, `is_ipv6`, `is_cidr`, `is_domain`, `is_url`), safe argument-array execution (`safe_exec`), path traversal prevention (`safe_path`), and regex secret scrubbing (`scrub_secrets`).
  - `config.uc`: UCI cursor operations, profile ID generation (`^p[0-9a-f]{8}$`), secure credential storage (`/etc/geovpn/profiles/<id>/auth`, mode 0600), and key material file writer.
  - `ovpn_parse.uc`: Strict allowlist `.ovpn` parser enforcing 128 KB config cap, 4096-char line cap, UTF-8 BOM / CRLF stripping, max 64 remotes, inline PEM/key block extractor (64 KB cap), TAP rejection, and dropping all external script/binary/logging directives (`up`, `down`, `plugin`, `script-security 3`, `log`, etc.).
  - `ovpn_render.uc`: Deterministic OpenVPN client renderer enforcing `route-nopull`, `pull-filter ignore "redirect-gateway"`, `script-security 2`, up/down hooks, and syslogging.
  - `state.uc`: Atomic tmpfs state storage in `/var/run/geovpn/state.json` and `/var/run/geovpn/update.json`.
  - `cli.uc`: Core CLI dispatcher for start, stop, restart, reload, prepare, teardown, hook, status, import, and panic.
- **Entry Points & Hooks**:
  - `openwrt/geovpn-core/files/etc/init.d/geovpn`: procd service definition (START=95, STOP=10) with automatic respawn and preparation hooks.
  - `openwrt/geovpn-core/files/usr/libexec/geovpn/ovpn-hook`: Sanitized environment extractor that writes only whitelisted keys to `/var/run/geovpn/hook.env` and invokes ucode `_hook`.
  - `openwrt/geovpn-core/files/usr/libexec/geovpn/spawn`: Double-fork detached runner for asynchronous background tasks.
  - `openwrt/geovpn-core/files/usr/bin/geovpn`: Front-end CLI executable.
- **Testing**:
  - `tests/unit/test_validators.py`: 10 test cases covering boundary values, empty strings, injections, and secret redaction.
  - `tests/unit/test_ovpn_parser.py`: 7 test cases covering valid profiles, hostile corpus (scripts/plugins/log/nested config), TAP rejection, and size/line limits.
  - `tests/unit/test_ovpn_render.py`: Golden config rendering tests.
  - `tests/unit/test_state.py`: Atomic state reading/writing tests.
