## 2. Technical Deliverables & Implementation Details

### 2.1 Multi-Protocol Profiles UI (`profiles.js`)
- Completely overhauled `openwrt/luci-app-geovpn/htdocs/luci-static/resources/view/geovpn/profiles.js`:
  - **Protocol & Provider Badges**: Renders colored badges for protocols (`OpenVPN` in orange, `WireGuard` in purple, `IKEv2` in blue) and providers (`Windscribe` in cyan/blue, `Generic` in neutral grey).
  - **Write-Only Secrets (NFR-18)**: Password and private key inputs use `type="password"` with `autocomplete="new-password"` and informative placeholders (`Enter new password (leave empty to keep unchanged)`). Existing secrets are never read from disk or prefilled into input values. If left blank, existing keys remain untouched.
  - **Shared Credential Support for OpenVPN & WireGuard**: Enhanced OpenVPN edit modal with a `Shared Credential Set` selector, allowing OpenVPN profiles to link to shared credentials alongside WireGuard.
  - **Action Buttons**: Each row provides direct actions:
    - *Connect / Active*: Highlights current active tunnel; switches active profile and reloads.
    - *Test*: Directly triggers pre-connection test for the single profile, rendering an interactive modal with real-time progress and immediate Connect option.
    - *Edit*: Opens protocol-aware modal tailored to OpenVPN (remotes, ciphers, raw config, auth, credentials) or WireGuard (host, port, public key, allowed IPs, addresses, DNS, MTU, keepalive, credentials, write-only keys).
    - *Delete*: Confirms and purges profile and configuration directory.
  - **Render Capping (FR-23)**: Capped at <= 200 rows to prevent DOM bloat on memory-constrained client browsers, with an advisory banner displayed if profile pools exceed 200.

### 2.2 Pre-Connection Test Panel (`testpanel.js`)
- Implemented `openwrt/luci-app-geovpn/htdocs/luci-static/resources/view/geovpn/testpanel.js`:
  - **Criteria Overview**: Summarizes active table 4300 isolation invariants, target URLs, and pass/warn/fail thresholds (`max_handshake_ms`, `max_latency_ms`, `max_loss_pct`).
  - **Zero-Idle Polling**: Polling timer is only scheduled upon initiating a test job. Calls `api.testStatus(job_id)` every 1.5s while running. Instantly cancels polling upon receiving `state: 'done'`, `state: 'cancelled'`, or error. Zero network/ubus traffic occurs while idle.
  - **Harmonized Latency Metric (`median_ms`)**: Supports both `median_ms` and `median` properties, correctly rendering measured HTTP probe latencies.
  - **Results Table**: Visualizes cached and live test results: Status badge (PASS/WARN/FAIL), Handshake latency, HTTP probe latency/loss, diagnostic hints, and individual Test/Connect buttons.
  - **"Connect to Best" Action**: Automatically ranks tested candidates (PASS > WARN, lowest median latency, lowest handshake) and initiates connection to the optimal profile upon user confirmation.
  - **Job Control & Manual Cleanup**: Includes "Cancel Job" (sends SIGTERM via `api.testCancel`) and "Clean Up Test State" (calls `api.testCleanup({ verify: true })`, reporting residual artifact counts).

### 2.3 Batch & Multi-File Importer (`importer.js`)
- Implemented `openwrt/luci-app-geovpn/htdocs/luci-static/resources/view/geovpn/importer.js`:
  - **Honest Limitations Notice Banner**: Explicitly cautions that Windscribe Stealth (Stunnel over TCP 443) and WStunnel (WebSocket) encapsulation protocols require proprietary closed-source wrapper binaries not supported in standard OpenWrt packages. Standard OpenVPN and WireGuard configurations are fully supported.
  - **Multi-File Upload & Drag-and-Drop**: Interactive dropzone with native `<input type="file" multiple accept=".ovpn,.conf">` support, client-side 128 KB validation, and automatic protocol sniffing.
  - **Batch Chunking**: Slices large file queues into sequential batches of <= 50 files (`MAX_BATCH_FILES`), preventing rpcd batch size rejections while aggregating summary reports.
  - **Preset Propagation**: Connects preset selection (`windscribe` vs `generic`) to imported profiles, activating server-side Windscribe normalizations (N1..N5).
  - **Shared Credential Manager**: Dropdown of existing credential sets plus modal to create new shared sets under `/etc/geovpn/credentials/` (0700/0600 root-only).
  - **Batch Preview Table**: Lists queued files with detected protocol badges, editable human names, size counters, and individual removal buttons prior to committing batch import via `api.importBatch`.

### 2.4 Rpcd & API Method Declarations (`api.js` & `geovpn.uc`)
- Extended `openwrt/luci-app-geovpn/htdocs/luci-static/resources/geovpn/api.js`:
