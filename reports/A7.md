## 1. Scope & Covered Requirements

- **Phase Objective**: Implement Phase A7 strongSwan / IKEv2 Protocol Driver & Packaging (§6.6, §7.1, §11 A7 of `PLAN_ADDENDUM.md`):
  - **IKEv2 Protocol Driver (`geovpn/drivers/ikev2.uc`)**:
    - Route-based IPsec client driver using Linux XFRM virtual interfaces (`geovpn0` with `if_id 4200` for active tunnel, `gvt0` with `if_id 4300` for test tunnel).
    - Isolated swanctl configuration rendering managing strictly `gv_active` and `gv_test_<jid>` connections.
    - Secret hygiene: passwords and shared secrets encoded as `0x<hex>` in `swanctl.conf`, preventing shell injection, escape character corruptions, or plaintext leakage.
    - Non-destructive daemon management: if `charon` is already running on the system, GeoVPN leaves it running; only if GeoVPN explicitly started the service (tracked via transient marker `/var/run/geovpn/we_started_charon`) is it stopped on shutdown.
    - Facts polling from `swanctl --list-sas`: parses state (`connected`, `connecting`, `down`), byte counters (`rx`, `tx`), virtual IP, endpoint IP, and handshake age.
    - Line budget constraint: driver strictly maintained $\le 400$ lines (356 lines, meeting NFR-19).
  - **Updown Lifecycle Script (`/usr/libexec/geovpn/ike-updown`)**:
    - Handles `up-client` and `down-client` strongSwan events.
    - Sets assigned Virtual IP (VIP) onto the XFRM interface (`geovpn0` or `gvt0`).
    - Extracts pushed DNS servers into `/var/run/geovpn/pushed_dns`.
    - Invokes GeoVPN lifecycle hooks (`/usr/bin/geovpn _hook`) for routing table and nftables updates.
  - **IKEv2 Profile Importers (`geovpn/ike_import.uc` & `geovpn/import.uc`)**:
    - strongSwan Android `.sswan` export parser (`parse_sswan`).
    - Smart-paste block parser (`parse_smart_paste`).
    - Content-sniffing auto-detection in `geovpn.import`.
    - Plaintext secrets stored exclusively in `0600` files (`/etc/geovpn/profiles/<id>/ike.secret` or `/etc/geovpn/credentials/`), NEVER stored in UCI.
  - **Test Engine Parallel Credential Isolation (§7.1 / Invariant T5)**:
    - Rejection of test execution (`parallel_session_refused`) when candidate profile shares credentials with an active IKEv2 tunnel.
  - **Packaging (`openwrt/geovpn-ikev2/Makefile`)**:
    - Architecture-independent package (`PKGARCH:=all`, Apache-2.0).
    - Exact modular strongSwan dependencies: `+geovpn-core +kmod-xfrm-interface +strongswan-charon +strongswan-swanctl +strongswan-mod-kernel-netlink +strongswan-mod-socket-default +strongswan-mod-eap-mschapv2 +strongswan-mod-xauth-generic +strongswan-mod-openssl +strongswan-mod-vici`.
  - **LuCI & Rpcd Integration**:
    - IKEv2 designated with "Experimental" badge in `widgets.js`.
    - Warning banner in `profiles.js` if `geovpn-ikev2` is not installed: `apk add geovpn-ikev2`.
    - Complete IKEv2 edit modal with write-only password and credential set selection.
    - 100% complete Persian translations and RTL logical CSS properties.
  - **Automated Tests (`tests/unit/test_ikev2.py`)**:
    - 12 comprehensive unit tests covering packaging, parser, driver lifecycle, hex secrets, facts parsing, parallel session refusal, and golden baseline regression.
- **Requirements touched**:
  - `FR-30`: IKEv2 client driver (EAP-MSCHAPv2, route-based XFRM interface).
  - `FR-32`: IKEv2 profiles (form, smart paste, .sswan import).

## 2. Technical Deliverables & Implementation Details

### 2.1 strongSwan Packaging & Dependencies (`openwrt/geovpn-ikev2/Makefile`)
- Created `openwrt/geovpn-ikev2/Makefile`:
  - Architecture-independent (`PKGARCH:=all`), licensed under Apache License 2.0.
  - Declares complete modular strongSwan runtime dependencies:
    - `+geovpn-core`
    - `+kmod-xfrm-interface`
    - `+strongswan-charon`
    - `+strongswan-swanctl`
    - `+strongswan-mod-kernel-netlink`
    - `+strongswan-mod-socket-default`
    - `+strongswan-mod-eap-mschapv2`
    - `+strongswan-mod-xauth-generic`
    - `+strongswan-mod-openssl`
    - `+strongswan-mod-vici`
- Bundles ISRG Root X1 CA cert at `openwrt/geovpn-core/files/usr/share/geovpn/ca/geovpn-isrg-x1.pem` (mode 0644).

### 2.2 Route-Based IPsec Updown Script (`/usr/libexec/geovpn/ike-updown`)
- Created `openwrt/geovpn-core/files/usr/libexec/geovpn/ike-updown` (mode 0755):
  - Handles `up-client` and `down-client` strongSwan event triggers.
  - Automatically identifies whether event corresponds to active connection (`geovpn0`, `/var/run/geovpn`) or test connection (`gvt0`, `/var/run/geovpn/test/<jid>`).
  - Installs assigned IPv4/IPv6 Virtual IP (VIP) from `PLUTO_MY_SOURCEIP` / `PLUTO_MY_SOURCEIP6` directly onto the XFRM interface.
  - Extracts pushed DNS server addresses from `PLUTO_DNS4_*` and `PLUTO_DNS6_*` environment variables and writes them to `pushed_dns`.
  - Generates `hook.env` with 0600 permissions and invokes `/usr/bin/geovpn _hook` to trigger policy routing updates, DNS redirection, and firewall state refreshes.

### 2.3 IKEv2 Driver (`geovpn/drivers/ikev2.uc`)
- Created `openwrt/geovpn-core/files/usr/share/ucode/geovpn/drivers/ikev2.uc` (356 lines):
  - **Loading Method (M2)**: Renders isolated configuration drop-ins to `/var/run/geovpn/swanctl.conf` or `/var/run/geovpn/test/<jid>/swanctl.conf`. Loads via `swanctl --load-conns --file <path>` and terminates/unloads via `swanctl --terminate --ike <name>` and `swanctl --unload-conn --name <name>`.
  - **Secret Hygiene**: Encodes passwords and PSKs as `0x<hex>` bytes (`secrets.eap-<name>.secret = 0x...`), preventing shell injection, escape character corruptions, or plaintext leakage.
  - **Route-Based XFRM**: Automatically brings up virtual XFRM interfaces with `if_id 4200` (`geovpn0`) or `4300` (`gvt0`), unifying IPsec routing with standard table 4200/4300 policy routing.
  - **Non-Destructive Daemon Management**: Checks if `charon` is running; if already started externally, leaves it untouched. Only stops charon if `/var/run/geovpn/we_started_charon` exists.
  - **Facts Extraction**: Parses `swanctl --list-sas` output to extract connection state, uptime, VIP, endpoint IP, and RX/TX byte counters.

### 2.4 Profile Import Parsers (`geovpn/ike_import.uc` & `geovpn/import.uc`)
- Created `openwrt/geovpn-core/files/usr/share/ucode/geovpn/ike_import.uc`:
  - `parse_sswan`: Parses strongSwan Android `.sswan` JSON export schema, extracting remote server, remote ID, EAP username, CA certificate, and DPD timeout.
  - `parse_smart_paste`: Parses multi-line key-value text blocks with server, username, and password tokens.
- Integrated into `openwrt/geovpn-core/files/usr/share/ucode/geovpn/import.uc`:
  - Sniffs `.sswan` file extensions and JSON content containing `uuid` and `remote`.
  - Sniffs smart-paste blocks.
  - Writes secrets to `0600` file `/etc/geovpn/profiles/<id>/ike.secret`, keeping UCI strictly devoid of plaintext secrets.

### 2.5 Test Engine Credential Collision Guard (`geovpn/test_engine.uc`)
- Updated `openwrt/geovpn-core/files/usr/share/ucode/geovpn/test_engine.uc`:
  - Enforces §7.1 / Invariant T5: if an IKEv2 test tunnel candidate shares username or credential set with an active IKEv2 tunnel, test engine aborts with `status: 'fail'` and `reason: 'parallel_session_refused'`.
  - Eliminates risks of gateway session hijacking or unexpected disconnects of active user tunnels.
  - Cleans up leftover IKEv2 test connections and XFRM interfaces upon test completion, test cancellation, or panic sweep.

### 2.6 LuCI & Rpcd Integration

  - Persists `ike_*` fields, `cred` set reference, and write-only passwords in `profile_save_raw`.
- Updated `openwrt/luci-app-geovpn/htdocs/luci-static/resources/geovpn/widgets.js`:

  - Updated `renderProtoBadge('ikev2')` to append the experimental badge automatically.
