### 2.3 Security, Quality & Licensing Review (§12)
- **Input Validation**:
  - Profile, credential, and test IDs strictly validated against `^[pct][0-9a-f]{8}$`.
  - Filesystem access confined to root-owned `0700` directories via `realpath` checks.
  - Test URLs strictly restricted to public HTTP/HTTPS endpoints; private IPs (RFC1918), loopback, link-local, and cloud metadata IPs (169.254.169.254) denied.
  - WireGuard parser rejects all script hooks (`PreUp`, `PostUp`), obfuscation parameters (`Jc`, `S1`), binary NUL bytes, and oversized lines.
  - Shell commands invoked strictly through `util.safe_exec` with argv arrays (no `eval`, no string-interpolated shell commands).
- **Secrets Management & Scrubber Enhancement**:
  - Private keys, PSKs, and passwords stored exclusively in mode `0600` files inside mode `0700` directories.
  - Web UI inputs are write-only (`type="password"`) and never prefilled with existing secrets.
  - Diagnostic exports, ubus RPC responses, import reports, and system logs are systematically scrubbed of sensitive material.
  - Secret scrubber (`util.scrub_secrets`) enhanced to scrub JSON-quoted secrets (`"password": "..."`, `"PrivateKey": "..."`, `"secret": "..."`), config assignments, and bare `0x<hex>` secrets, eliminating leaks across JSON RPC and structured logs.
- **Licensing & Re-use (C-06)**:
  - Audited repository: zero lines of GPL/AGPL code vendored or embedded.
  - Upstream tools (`wg`, `swanctl`, `openvpn`) interacted with purely across standard process boundaries.
  - Complete `NOTICE` file maintains attribution for all runtime dependencies and design references.

## 5. Residual Risks & Mitigations

| ID | Risk | Severity | Status & Mitigation |
|---|---|---|---|
| **RA-01** | strongSwan package availability / feed lag | Low | Mitigated: strongSwan is isolated in optional `geovpn-ikev2` / `geovpn-full`. Base `geovpn` install remains 100% functional without strongSwan. |
| **RA-02** | Windscribe IKEv2 server proposal drift | Low | Mitigated: Standard strongSwan default proposals accepted by Windscribe commercial gateways; manual proposals override supported in UI. Labeled *experimental*. |
| **RA-03** | User swanctl configuration clobbering | Negligible | Mitigated: Drop-in M2 configuration fragments used with `--load-conns --file` and `--unload-conn`; user connections untouched. |
| **RA-04** | Test traffic leak to WAN | Negligible | Mitigated: Invariant T2 strictly enforced; table 4300 initialized with `unreachable default` before interface is raised. |
| **RA-05** | Orphan test artifacts after unexpected crash | Negligible | Mitigated: Reversible journal-before-action, element timeouts (90s), and `geovpn test-cleanup` executed on restart/panic. |
| **RA-06** | Parallel session kicking active tunnel | Low | Mitigated: Active profile tested via live check; test engine warns for WG/OVPN and strictly refuses IKEv2 test with same credentials. |
| **RA-07** | Failover flapping | Negligible | Mitigated: Hysteresis counters (3 ticks), minimum switch interval (60s), hourly cap (6 switches/hr), exponential backoff. |
| **RA-08** | WireGuard AllowedIPs partial or invalidation | Low | Mitigated: Parser mandates default route coverage; informative notices guide user to regenerate configs if keys expire. |
| **RA-12** | License contamination | Negligible | Mitigated: Strict C-06 enforcement; zero lines of GPL/AGPL vendored code; Apache-2.0 clean. |
| **RA-15** | CPU contention during pre-connection test | Low | Mitigated: Concurrency strictly capped at 1 real test; preflight validates RAM >= 48 MB and 1-min load <= 3.0. |
