## 2. Technical Deliverables & Implementation Details

### 2.1 Driver Abstraction (`drivers/common.uc`)
- Implemented `usr/share/ucode/geovpn/drivers/common.uc` (118 lines):
  - `create_context(kind, profile_id, overrides)`: Constructs runtime context `{ kind, profile_id, dev, table, mark, rundir }`. Defaults to `geovpn0`, table `4200`, mark `0x01000000` (`0x0f000000`) for active tunnels, and `gvt0`, table `4300`, mark `0x03000000` for test tunnels.
  - `exec(argv, stdin_str)`: Safe child execution without shell `eval`, returning `{ code, stdout, stderr }`.
  - `create_journal(ctx)` / `journal_record(j, step, undo_action)` / `journal_rollback(j)`: Transactional journal for lifecycle step reversibility.
  - `get_driver(proto)` / `list_drivers()`: Dynamic driver registry and resolver.

### 2.2 OpenVPN Driver (`drivers/openvpn.uc`)
- Extracted `usr/share/ucode/geovpn/drivers/openvpn.uc` (349 lines):
  - Uniform lifecycle interface: `available()`, `validate(profile)`, `endpoints(profile)`, `render_ovpn(profile, pdir, ctx)`, `prepare(profile, ctx)`, `start(profile, ctx)`, `facts(ctx)`, `refresh(ctx)`, `stop(ctx)`, `cleanup(ctx)`.
  - Parameterized by context: dynamically binds device (`geovpn0` vs `gvt0`), routing table, marks, and environment (`GV_CTX`).
  - Passes all active tunnel parameters identically to previous baseline rendering.
  - Embedded Windscribe normalization rules N1/N2 and cipher mapping.

### 2.3 Backward-Compatible Shim (`ovpn_render.uc`)
- Converted `usr/share/ucode/geovpn/ovpn_render.uc` to a thin adapter:
  - Exports `render_ovpn(profile, pdir)` directly invoking `drv_ovpn.render_ovpn(profile, pdir, drv_common.create_context("active", profile.id))`.
  - Existing scripts and legacy callers maintain identical call signatures without modification.

### 2.4 OpenVPN Parser Extensions (`ovpn_parse.uc`)
- Extended allowlist:
  - Added support for `ping`, `ping-restart`, `ping-exit`, `explicit-exit-notify`, `comp-lzo`.
  - NCP alias translation: Automatically maps deprecated `ncp-ciphers` to modern `data-ciphers`.
  - Windscribe provider detection: Identifies Windscribe profiles via domain/comment fingerprints.
  - NUL-byte rejection: Files containing binary NUL characters (`\0`) are immediately rejected.
  - Keepalive N1/N2 normalization:
    - **N1**: Rewrites `ping-exit N` into `ping-restart N`.
    - **N2**: If any ping directive (`ping`, `ping-restart`, `ping-exit`) is explicitly defined, the default `keepalive 10 60` directive is suppressed, preventing OpenVPN startup conflicts.

### 2.5 Migration Engine (`config.uc` & `91-geovpn-migrate`)
- **Safe write helper (`write_file_safe`) & stream reader (`read_file_safe`)**:
  - Identified that standard `fs.writefile()` in the OpenWrt ucode runtime has a chunk write limit of ~384 bytes.
  - Implemented `write_file_safe()` and `read_file_safe()` using explicit file stream handles (`let f = fs.open(...); f.write(...); f.close();`) to ensure arbitrary size payloads are read and written completely and atomically.
- **Migration logic (`migrate_v1_to_v2`)**:
  - Automatically creates a timestamped file backup in `/etc/geovpn/backup/geovpn.v1.<epoch>` (0600) containing `/etc/config/geovpn` prior to any mutations.
  - Upgrades UCI `main.config_version` to `'2'`.
  - Inserts default `test` and `autoconnect` configuration sections if missing.
  - Upgrades all legacy v1 profiles by populating `option proto 'openvpn'`.
  - Strictly idempotent: safe to execute multiple times without mutating or duplicating sections.
- **Rollback logic (`rollback_migration`)**:
  - Discovers the latest backup file and cleanly restores `/etc/config/geovpn`.
- **Downgrade preparation (`prepare_downgrade`)**:
  - Reverts `config_version` to `'1'`, verifies active profile is OpenVPN (swapping to first OpenVPN profile if a non-OpenVPN profile was active), and emits warnings for any non-OpenVPN profiles.
- **Boot & Installation Hook (`/etc/uci-defaults/91-geovpn-migrate`)**:
  - Runs upon package installation and first boot.
  - Dual-mode execution: runs via ucode if available, with a resilient POSIX shell + `uci -c ... -P ...` fallback (verified functional even when `ucode` is missing from PATH).
- **CLI Commands (`usr/share/ucode/geovpn/cli.uc` & `/usr/bin/geovpn`)**:
  - Added CLI verbs: `geovpn migrate`, `geovpn rollback`, `geovpn prepare-downgrade`.

### 2.6 Sysupgrade & Runtime Isolation
- Updated `/lib/upgrade/keep.d/geovpn` to preserve `/etc/geovpn/credentials` and `/etc/geovpn/backup` across router sysupgrades.
- Updated `/usr/libexec/geovpn/ovpn-hook` to isolate test hooks under `/var/run/geovpn/test/<id>/hook.env` and pass the path to `geovpn _hook`.
