## 2. Technical Deliverables & Implementation Details

### 2.1 Unified Multi-Protocol Import Engine (`import.uc`)
- Implemented `openwrt/geovpn-core/files/usr/share/ucode/geovpn/import.uc` (667 lines):
  - **Content Sniffing & Dispatching**:
    - `sniff_kind(content, filename)`: Inspects text markers (e.g. `[Interface]`, `[Peer]` vs `client`, `dev tun`, `remote`) and file extensions (`.conf`, `.ovpn`) to reliably route content to `wg_parse.uc` or `ovpn_parse.uc`.
  - **Automatic Clean Naming**:
    - `normalize_name(filename)`: Strips extensions, converts underscores/hyphens to spaces, collapses whitespace, and falls back to endpoint hostname if filename is generic.
  - **Dual Deduplication**:
    - Content hash: Computes SHA-256 fingerprint using temporary file and `sha256sum` to detect exact duplicate configurations across imports.
    - Endpoint fingerprint: Computes `proto:host:port:key|ca` to detect overlapping server configurations.
    - Deduplication policies: Supports `skip` (default: skip duplicate and report), `replace` (update existing profile), and `keep_both` (create new profile with incremented numeric suffix `(1)`, `(2)`).
  - **Resource Bounds & Protection**:
    - Enforces `MAX_BATCH_FILES = 50` to prevent denial-of-service or memory exhaustion on embedded routers.
    - Enforces `MAX_PROFILES = 100` system-wide profile cap.
    - Rejects hostile inputs: oversized payloads (>128 KB), binary NUL bytes, shell execution hooks, invalid syntax.
  - **Atomic Transactional Rollback**:
    - Tracks created profile IDs during batch execution. On unhandled failure or fatal validation errors, executes atomic rollback: deletes all newly created UCI sections, unlinks disk files/credentials, and reverts cursor changes.
  - **Windscribe Normalization Suite (N1..N5)**:
    - **N1**: Converts `ping-exit <n>` directives to `ping-restart <n>` for persistent reconnection resilience.
    - **N2**: Suppresses default OpenVPN `keepalive` directive if explicit `ping` / `ping-restart` options exist.
    - **N3**: Deduplicates multiple identical or equivalent `remote` endpoint directives.
    - **N4**: Clamps WireGuard MTU to 1420 (keepalive default 25 s); clamps OpenVPN MTU to 1500 and MSS to 1450.
    - **N5**: Maps pushed DNS `10.255.255.3` and tags `provider = 'windscribe'`. Emits actionable warnings if WireGuard keys need regeneration.
  - **Stealth & WStunnel Detection**:
    - Detects Stealth (stunnel/obfs4 port 443/8443) and WStunnel (WebSocket port 443) indicators in filename or remote configurations. Emits clear advisory notice that custom encapsulation protocols require external client daemons.
