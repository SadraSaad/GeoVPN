## 2. What Was Implemented
- **rpcd ucode Plugin (`/usr/share/rpcd/ucode/geovpn.uc`)**:
  - Implements `status`: Service status, tunnel stats, split mode, RX/TX counters.
  - Implements `logs`: Reads syslog filtered by `geovpn` with PEM and password scrubbing.
  - Implements `import_ovpn`: Imports, checks 128 KB cap, parses via strict allowlist.
  - Implements `profile_set_credentials`: Sets username/password in `/etc/geovpn/profiles/<id>/auth` (mode 0600; never echoed).
  - Implements `profile_put_material`: Saves individual cert/key materials per role.
  - Implements `profile_delete`: Removes profile folder and UCI section.
  - Implements `service`: start, stop, restart, reload, or switch active profile.
  - Implements `panic`: Emergency teardown of all nftables/routing/dnsmasq state.
  - Implements `geo_catalog`: Server-side pagination, search filtering, and estimated RAM calculation.
  - Implements `geo_update` and `geo_update_status`: Detached update execution.
  - Implements `test_target`: Predicts routing path (direct vs vpn) and reports layer/rule reasons.
  - Implements `diag`: Runs system checks and conflict scans.
- **Diagnostics & Path Simulator (`/usr/share/ucode/geovpn/diag.uc`)**:
  - `run_diag()`: Checks TUN device, OpenVPN binary, dnsmasq nftset support, nftables, flow offloading, and pbr/mwan3 conflicts.
  - `test_target()`: Implements packet classification order matching §5.3, with numeric CIDR match evaluator (`match_cidr4`).
  - `get_scrubbed_logs()`: Masks certificates, keys, and credentials.
- **ACL JSON (`root/usr/share/rpcd/acl.d/luci-app-geovpn.json`)**:
  - Least-privilege access granting read and write rights on UCI `geovpn` and `luci.geovpn` ubus methods.
- **Testing**:
  - `tests/unit/test_diag.py`: Tests numeric CIDR matching and path prediction logic across bypass/include modes.
  - `tests/unit/test_rpcd_api.py`: Validates that ACL JSON covers all 13 ubus methods and UCI sections.
