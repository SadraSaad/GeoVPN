## 2. Technical Deliverables & Implementation Details

### 2.1 WireGuard Config Parser (`wg_parse.uc`)
- Implemented `openwrt/geovpn-core/files/usr/share/ucode/geovpn/wg_parse.uc` (256 lines):
  - **Strict INI Parser**: Line-by-line parser with comment stripping (`#` and `;`), whitespace trimming, case-insensitive section and key matching.
  - **Single Peer Enforcement**: Requires exactly one `[Interface]` and exactly one `[Peer]` section; configurations with multiple peers are explicitly rejected (`Multiple [Peer] sections are not supported: single-peer profiles only`).
  - **Hostile Corpus Defense**:
    - Rejects all shell execution hooks (`PreUp`, `PostUp`, `PreDown`, `PostDown`) with explicit security reason (FA-12).
    - Rejects AmneziaWG obfuscation directives (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`, `H2`, `H3`, `H4`) with explicit message (`Obfuscation parameters (...) are not supported by kernel WireGuard`, VA-15).
    - Enforces 128 KB config size cap, 4096-char line length cap, and binary NUL byte (`\0`) rejection.
    - Strips UTF-8 BOM (`\ufeff` / `\xef\xbb\xbf`) cleanly if present.
  - **Key & Address Validation**:
    - Validates 32-byte base64 keys (`PrivateKey`, `PublicKey`, `PresharedKey`) via `util.is_wireguard_key()`.
    - Validates IPv4/IPv6 CIDR interface addresses via `util.is_cidr()`.
    - Filters DNS entries: keeps valid IPv4/IPv6 literals, ignores non-IP search domains with warning.
    - Parses IPv4, IPv6, and bracketed IPv6 endpoints (`[2001:db8::1]:51820`).
  - **Default Route Coverage Enforcement**:
    - Validates that `AllowedIPs` contains `0.0.0.0/0` unless `wg_allow_partial=1` is explicitly set. Profiles with narrow `AllowedIPs` are rejected with the explanatory error required by PLAN_ADDENDUM §5.3.2.
  - **Windscribe Auto-Detection**:
    - Identifies Windscribe configs via `.windscribe.com` endpoint host or `10.255.255.3` DNS resolver.
    - Applies defaults (`wg_mtu = 1420`, `wg_keepalive = 25`) and generates actionable hints if keys are invalidated server-side.

### 2.2 WireGuard Protocol Driver (`drivers/wireguard.uc`)
- Implemented `openwrt/geovpn-core/files/usr/share/ucode/geovpn/drivers/wireguard.uc` (359 lines):
  - **Full Lifecycle Contract**: Exports `proto`, `available()`, `validate(profile, cfg)`, `endpoints(profile)`, `prepare(profile, ctx)`, `start(profile, ctx)`, `facts(ctx)`, `refresh(ctx)`, `stop(ctx)`, `cleanup(ctx)`.
  - **Direct Kernel Execution (D-A2)**:
    - Directly executes `/sbin/ip` and `/usr/bin/wg` via `util.safe_exec()`.
    - Never touches netifd `proto wireguard` or UCI `network`, preventing netifd from installing routes from `AllowedIPs` into the main routing table.
  - **Argv Secrets Isolation (NFR-18)**:
    - Private and preshared keys are written to 0600 files under `/etc/geovpn/profiles/<id>/` or `ctx.rundir`.
    - `wg set` is invoked with `private-key <filepath>` and `preshared-key <filepath>`. Raw secret key bytes never appear in process `argv`, preventing leakage in `ps`, `/proc`, or logs.
  - **Cryptokey Routing**:
    - `AllowedIPs` are passed to `wg set ... allowed-ips` for kernel WireGuard encryption filtering only, and are never turned into OS routes (`route_allowed_ips=0` equivalent).
  - **Facts Dump Parsing**:
    - Parses `wg show <dev> dump` output for peer public key, endpoint IP, latest handshake timestamp, transfer rx/tx bytes.
    - Accurately reports state: `connecting` (handshake == 0), `connected` (handshake age <= 180 s), `stale` (handshake age > 180 s), `down` (interface missing).
  - **Dynamic Endpoint Re-Resolution**:
    - In `refresh(ctx)`, re-resolves endpoint hostnames using system DNS and updates kernel peer endpoint on WAN hotplug events or health tick runs.
  - **Context Awareness**:
    - Dynamically binds to `geovpn0` (table 4200) in `active` context and `gvt0` (table 4300) in `test` context.
  - **Modularity Budget (NFR-19)**:
    - Exactly 359 lines of ucode, well within the 400-line ceiling.

### 2.3 Driver Dispatcher & Importer Integration
- Updated `openwrt/geovpn-core/files/usr/share/ucode/geovpn/drivers/common.uc`:
  - Registered `wireguard` driver in `get_driver()` and `list_drivers()`.
- Updated `openwrt/geovpn-core/files/usr/share/ucode/geovpn/config.uc`:
  - `create_profile()` maps WireGuard UCI options (`wg_endpoint_host`, `wg_endpoint_port`, `wg_public_key`, `wg_address`, `wg_dns`, `wg_allowed_ips`, `wg_mtu`, `wg_keepalive`, `wg_has_psk`, `wg_allow_partial`) and writes keys to 0600 files on disk. Secrets never enter UCI.
  - `get_profile()` normalizes address/DNS lists and inspects `wg.key` / `wg.psk` presence.
- Updated `openwrt/geovpn-core/files/usr/share/ucode/geovpn/cli.uc`:
  - Extended `geovpn import` to sniff file content: lines containing `[Interface]` are parsed via `wg_parse.uc`, while OpenVPN files are parsed via `ovpn_parse.uc`.
- Updated `openwrt/geovpn-core/files/usr/share/ucode/geovpn/nftgen.uc` and `dnsgen.uc`:
  - WireGuard endpoint IPs/hostnames are automatically included in `always4`/`always6` interval sets and dnsmasq direct server rules, preventing routing loops.
  - Pushed WireGuard DNS (e.g. `10.255.255.3`) is staged to `/var/run/geovpn/pushed_dns` so `dns_vpn_servers: pushed` resolves seamlessly.
