## 2. What Was Implemented
- **Module (`/usr/share/ucode/geovpn/dnsgen.uc`)**:
  - `find_confdir()`: Scans `/var/etc/dnsmasq.conf.*` for instance-specific `conf-dir=` (supporting per-instance `/tmp/dnsmasq.cfgXXXXXX.d` and standard `/tmp/dnsmasq.d`).
  - `render_dnsmasq_conf()`:
    - Pins upstream DNS per domain: `server=/d1/d2/.../<upstream-dns>`.
    - Populates nftables sets on resolution: `nftset=/d1/d2/.../4#inet#geovpn#geo4_dyn,6#inet#geovpn#geo6_dyn`.
    - Handles infrastructure hosts (VPN servers always routed via direct DNS).
    - In `bypass` mode, emits `no-resolv` and points default server lines to VPN DNS upstreams.
    - Firefox/browser canary domain NXDOMAIN (`address=/use-application-dns.net/`).
    - Enforces max 48 domains per line and <= 900 bytes per directive (`chunk_domains`).
  - `apply_dnsmasq()`: Hash-checked atomic write (`.tmp` -> `mv`) with `/etc/init.d/dnsmasq restart` triggered only when content changes.
  - `teardown_dnsmasq()`: Removes `geovpn.conf` and reloads clean dnsmasq.
- **Hotplug Event Handler**:
  - `openwrt/geovpn-core/files/etc/hotplug.d/iface/50-geovpn`: Listens for `ifup` on `wan` and `wan6`, dispatches debounced refresh via spawn launcher.
- **Testing**:
  - `tests/unit/test_dnsgen.py`: Validates domain chunking bounds, directive byte lengths, and bypass/include configuration output.
