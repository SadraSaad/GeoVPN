## 2. Technical Deliverables & Implementation Details

### 2.1 Pre-Connection Test Engine Core Library (`test_engine.uc`)
- Implemented `openwrt/geovpn-core/files/usr/share/ucode/geovpn/test_engine.uc` (1,244 lines):
  - **Job Lifecycle & Concurrency (T5)**:
    - `acquire_lock(job_id)` / `release_lock()`: Enforces 1 active test job via `/var/run/geovpn/test.lock`. Cleans stale locks if the recorded PID is dead (`kill -0` check).
  - **Journal-Before-Action (T4)**:
    - `journal_init(job_id)`, `journal_record(job_id, entry)`, `journal_get(job_id)`, `journal_rollback(job_id)`: Logs every artifact (ip rule, ip route, net link, nft chain, nft set, procd service, pid file) to `/var/run/geovpn/test/<job_id>/journal.json` BEFORE creation. Replays entries in reverse order on cleanup.
  - **Fail-Closed Test Routing (T2, C-07)**:
    - `setup_test_routing(job_id, table, prio)`: Installs `ip -4 route add unreachable default table 4300` and `ip -6 route add unreachable default table 4300` BEFORE `gvt0` is raised. Adds `ip rule add fwmark 0x03000000/0x0f000000 lookup 4300 pref 701`.
  - **SSRF Validation & Conflict Guard (T3, T7)**:
    - `validate_target_url(target_url)`: Rejects private IPs (RFC1918), loopback (`127.0.0.1`, `::1`, `localhost`), link-local (`169.254.0.0/16`, `fe80::/10`), cloud metadata (`169.254.169.254`), and URLs containing userinfo.
    - `check_target_conflict(ip, port, main_cfg, active_profile)`: Cross-references target IP/port against active VPN remote endpoints and DNS resolvers, refusing colliding targets.
  - **Monotonic Probing (FR-36)**:
    - `execute_probe(kind, target_url, timeout_s, dev, samples)`: Uses monotonic clock (`clock()`) to measure handshake and HTTP 204 response timing. Computes sample count, min, median, jitter, and loss percentage.
  - **WireGuard Test Procedure (§7.3.1)**:
    - `test_wireguard_profile(job_id, profile, options)`: Creates `gvt0` via `ip link add dev gvt0 type wireguard`, sets private key via descriptor/file (0600), configures peer endpoint and AllowedIPs, installs default route metric 10 in table 4300, polls `wg show gvt0 dump` for handshake completion, executes HTTP probe, and tears down.
  - **OpenVPN Test Procedure (§7.3.2)**:
    - `test_openvpn_profile(job_id, profile, options)`: Spawns isolated test OpenVPN instance via `geovpn-test` procd script with `GV_CTX=test:<id>`. Sets up test routing on `gvt0`, executes HTTP probe, and stops service via procd.
  - **Active Profile Live Check (T6)**:
    - `run_live_check(profile, opts, profile_id)`: If candidate profile is currently active, bypasses secondary tunnel creation and performs non-intrusive probe over active tunnel.
  - **Credential Collision Guard (T6)**:
    - Checks candidate profile credentials against active tunnel. If credentials match for IKEv2, refuses test to prevent remote session disconnection; for OpenVPN/WireGuard, emits warning.
  - **Scoring & Ranking (§7.5)**:
    - `score_result(res, test_cfg)`: Evaluates results against `max_handshake_ms`, `max_latency_ms`, and `max_loss_pct`, scoring as `pass`, `warn`, or `fail`.
    - `rank_results(results)`: Ranks profiles by status (pass > warn > fail), lowest median probe latency, and lowest handshake latency.
  - **Zero-Residual Cleanup & Verification (T4, T8)**:
    - `test_cleanup(job_id, verify)`: Unwinds journals, flushes table 4300, removes rule 701, deletes `gvt0`, stops test procd instances, and removes test directories.
    - `verify_clean_state()`: Verifies rule 701, table 4300, interface `gvt0`, test nft sets, test directories, and test locks are completely absent.

### 3.2 Audited Defect Remediations
1. **Live Check Routing Leaks (T1/T6)**: Fixed `run_live_check()` to mark probe packets with `0x01000000` (`fetch_vpn4/6`) into active table 4200 rather than test table 4300, and immediately cleaned transient journals.
2. **OpenVPN Context & Options (§7.3.1)**: Passed `profile_id` instead of `job_id` so keys/certs load from the profile directory; added `connect-timeout 10` and `connect-retry-max 1`.
3. **SSRF DNS Rebinding & IPv4-Mapped IPv6 (T7)**: Retained loopback addresses in resolver parsing to reject rebinding domains; added support for dotted/hex `::ffff:` IPv4-mapped IPv6.
4. **Journal-Before-Action Ordering (T4)**: Enforced journaling *prior* to `safe_exec` invocation across `setup_test_nft`, `add_test_endpoint`, and `add_test_target`.
5. **Handle-Based nftables Rule Deletion (T1/T8)**: Replaced failed text deletion with handle-based deletion via `nft -a list chain inet geovpn out` and `nft delete rule ... handle <id>`, preventing accumulation of rules and `EBUSY` set deletion errors.
6. **Scoring Null URL Failure (§7.5)**: Scored result as `fail` with `http_failed` whenever `require_http=1` and `metrics.url` is null or has 0 ok samples.
7. **Resource Preflight Checks (FR-43 / §7.8)**: Implemented `check_resource_preflight` checking `/proc/meminfo` and `/proc/loadavg` against configured limits.
8. **Process Suicide Prevention in Cancellation (T5 / §7.11)**: Compared caller PID against `test.lock` PID in `test_cancel` to avoid killing the cleanup process before termination, and preserved `job.json` for status queries.
9. **Bounded Probe Fallback (VA-04)**: Added `-w <timeout>` to busybox `nc` fallback probes to avoid hanging indefinitely on dropped SYNs.
