## 2. What Was Implemented
- **Data Pack Compiler (`data-pack/build_pack.py`)**:
  - Compiles flat per-category files from upstream sources (ipverse CC0, domain-list-community MIT).
  - Recursively collapses redundant subdomains (`collapse_subdomains`).
  - Aggregates and collapses overlapping CIDR blocks (`collapse_cidrs`).
  - Produces catalogs: `catalog/geoip.tsv` and `catalog/geosite.tsv` with row hashes and byte sizes.
  - Produces `MANIFEST` (schema=1, build_id, build_time, sha256 checksums of catalogs).
  - Emits curated `misc/doh-resolvers.txt` and bundles full upstream license texts under `LICENSES/`.
- **Router-Side Updater (`/usr/share/ucode/geovpn/data.uc`)**:
  - Fetches manifest via `uclient-fetch` and verifies cryptographic ed25519 signature via `usign`.
  - Monotonic timestamp validation prevents downgrade attacks.
  - Verifies two-level Merkle-lite integrity (manifest -> catalog TSV -> individual category files).
  - Selective downloading: fetches only categories explicitly enabled in UCI.
  - Per-line validation (CIDR / domain syntax) rejecting files with >0.5% invalid lines.
  - Atomic directory swap (`data` -> `data.prev`, `data.new` -> `data`) with automatic fallback to `data.prev` on failure.
  - Maintains crontab job in `/etc/crontabs/root` bounded by `# geovpn begin/end` markers.
  - Real-time progress reporting via tmpfs `/var/run/geovpn/update.json`.
- **Updater Entry Point**:
  - `openwrt/geovpn-core/files/usr/bin/geovpn-update`: CLI and cron wrapper.
- **Testing**:
  - `data-pack/tests/test_build_pack.py`: Tests subdomain collapsing, CIDR aggregation, and manifest hash pinning.
  - `tests/unit/test_data_updater.py`: Tests TSV catalog parsing, downgrade check, and crontab marker management.
