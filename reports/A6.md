## 2. Technical Deliverables & Implementation Details

### 2.1 Health Tick & Failover Engine (`geovpn/health.uc`)
- Created `openwrt/geovpn-core/files/usr/share/ucode/geovpn/health.uc`:
  - **State Persistence**: `/var/run/geovpn/health.json` tracks `fail_count`, `last_tick`, `last_health`, `last_switch`, `switch_history` (rolling 1-hour window), `backoff_step`, `backoff_until`, and `alert`.
  - **Concurrency Control**: `/var/run/geovpn/health.lock` with atomic file creation and 60-second stale lock expiration.
  - **Live Health Assessment**: Calls `te.run_live_check(active_profile, null, active_id)`. Categorizes status into `healthy`, `degraded` (warn), `failing` (probe failed), or `down` (tunnel disconnected / no handshake).
  - **Hysteresis & Down Grace**: Gated by `fail_threshold` (default 3 ticks) and `down_grace` (default 30s) before triggering failover.
  - **Rate Limiting**: Enforces `min_switch_interval` (>= 60s) and `max_switches_per_hour` (<= 6/hr) based on `switch_history`.
  - **Candidate Selection & Test-Before-Switch**:
    - Mode `fallback`: evaluates configured ordered list `auto_cfg.fallback`.
    - Mode `best` or general failover: ranks enabled profiles in `auto_pool=1`.
    - Skips current active profile. Limits candidates to `failover_max_candidates` (default 3).
    - Tests candidate in isolation via `te.test_profile(cand_id)` (or reuses recent pass <= `test_ttl`).
    - If a candidate passes, executes `switch_active_tunnel(cand_id, persist_switch)` and resets failure counters.
    - If all candidates fail, applies exponential backoff schedule `[60, 120, 240, 480, 960, 1800]` seconds and raises alert banner.
  - **Candidate Endpoint IP Seeding**: Extracts endpoint hosts/IPs from profile, resolves hostnames, and injects them into nftables sets `always4/always4_dyn` and `always6/always6_dyn` before tunnel switch.
  - **Runtime Override vs Persist Switch**:
    - Runtime switch (default `persist_switch=0`) writes target ID to `/var/run/geovpn/active_override`, leaving flash UCI untouched.
    - Persistent switch writes `active_profile` to UCI, commits, and removes `active_override`.
  - **Failback Logic**: When runtime override is active and `failback=1`, tests primary profile. After 3 consecutive passes, safely switches back.
  - **Cron Manager**: `update_cron_schedule` updates `/etc/crontabs/root` between `# geovpn health begin` and `# geovpn health end` markers with `* * * * * /usr/bin/geovpn health-tick`.

### 2.6 Adversarial Review Findings & Fixes
1. **LuCI RPC Parameter Stripping**: In `api.js`, `callService` had `params: ['action', 'profile']`. Invoking `switchProfile(id, 1)` silently dropped `persist` because LuCI RPC only passes declared parameter keys. Fixed by adding `'persist'` to `callService` parameters.
2. **LuCI "Run Health Check Now" Failure**: `autoconnect.js` called `api.callService('status')` on button click, which was rejected with `INVALID_ACTION: Unknown service action`. Fixed by exposing `health_tick` in RPCD and invoking `api.runHealthTick(true)`.
3. **Candidate Pool Unranked in `mode=best`**: `health.uc` selected candidates using arbitrary UCI dictionary ordering instead of ranking them by recent test metrics. Fixed by integrating `te.rank_results(cached, c.test)`.
4. **Permanent Failback Invalidation**: When `persist_switch=1`, the primary profile was overwritten in UCI without storing the original primary ID. Fixed by preserving `original_primary` in `health.json` across temporary and persisted switches.
5. **NTP Step Backward Lock Stalling**: `health.lock` checked `time() - st.mtime > 60`. If the router clock stepped backward, `time() - st.mtime` became negative, locking health ticks indefinitely. Fixed by adding recovery for future mtime locks (`st.mtime > now`).
6. **Init Script Restart Execution & Mocking**: `health.uc` guarded service restart with `if (fs.stat(init_script))`, preventing execution in environments without `/etc/init.d/geovpn` and blocking test verification. Fixed by executing unconditionally through `safe_exec` (with `GEOVPN_INIT_SCRIPT` override support) and adding test hook support (`global._safe_exec_hook`) in `util.safe_exec`.
7. **Timing Race in Unit Tests**: Asserting exact timestamp `now + 60` failed when subprocess execution spanned a second boundary. Fixed with bounded tolerance assertions (`delta=2`).
8. **Missing `switch` command in `/etc/init.d/geovpn`**: Handled WireGuard / IKEv2 profiles in `start_service` without failing on nonexistent `.conf` and exposed `switch()` in `EXTRA_COMMANDS`.
